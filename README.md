# Roadmap Gambar Anime dari Foto (0 → 100)

Website statis (HTML/CSS/JS, tanpa build) berisi roadmap 30 hari, centang progres, ilustrasi target tiap tahap, dan kata kunci pencarian YouTube.

## Struktur file
```
index.html   → halaman utama
style.css    → tampilan (otomatis terang/gelap)
script.js    → data jadwal, ilustrasi tahap, centang (tersimpan di browser)
README.md    → petunjuk ini
```

## Pasang di GitHub Pages
1. Buat repository baru, upload keempat file di root.
2. Settings → Pages → Source: *Deploy from a branch* → branch `main`, folder `/ (root)` → Save.
3. Buka `https://USERNAME.github.io/NAMA-REPO/` setelah 1–2 menit.

## Privasi
Foto referensi dipilih lewat tombol di halaman dan hanya tampil di browser. Jangan commit foto orang lain (terutama anak sekolah) ke repo publik.
